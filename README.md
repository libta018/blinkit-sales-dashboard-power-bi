# Blinkit Sales Dashboard (Power BI)

An interactive Power BI dashboard that analyzes Blinkit outlet and item sales by item attributes (fat content, item type) and outlet attributes (size, location, type, establishment year).

![Dashboard](images/dashboard.png)

## Business problem
Retail and quick-commerce teams need to see quickly which products and outlets drive sales and how performance differs across outlet size, location and type. This dashboard lets a user filter the data and compare performance in a few clicks.

## Dataset
Blinkit grocery sales data (items and outlets). [Add dataset source / link and number of rows]

Main fields used: item fat content, item type, outlet size, outlet location type, outlet type, outlet establishment year and sales.

## Tools used
- **Power BI Desktop**: data model, KPI cards, slicers, interactive visuals
- Data cleaning and transformation in Power BI

## Dashboard contents
- **KPI cards** for the key sales metrics
- **Fat content:** donut chart, and a bar chart of fat content by outlet
- **Item type:** bar chart comparing item categories
- **Outlet size:** donut chart
- **Outlet location:** funnel chart
- **Outlet establishment year:** line chart showing the trend
- **Outlet type:** pivot table
- **Slicers** to filter by outlet and item attributes, and a Q&A visual to ask questions in plain language
